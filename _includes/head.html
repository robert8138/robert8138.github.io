{% comment %} Translations advertise each other to search engines only. Posts are paired by a shared `ref:` in their front matter, and nothing renders in the body, so a reader reaches the other language by knowing the URL (prepend /zh) or by searching in that language. Emitting hreflang for a page with no counterpart would be a lie, hence the size check. {% endcomment %} {% if page.ref %} {% assign all_docs = site.posts | concat: site.pages %} {% assign translations = all_docs | where: "ref", page.ref %} {% if translations.size > 1 %} {% for t in translations %} {% endfor %} {% endif %} {% endif %}
