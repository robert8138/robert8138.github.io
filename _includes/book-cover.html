{% comment %} A book cover from Open Library, with a typeset fallback. Two ways to point at a cover, because ISBN does two different jobs: cover_id an Open Library *cover* ID (/b/id/). This is the cover OL itself picked for the work, so it is almost always the edition a reader would recognise. Preferred. isbn the book's identity, and the join key to _books/. Works as a cover source too (/b/isbn/), but a given ISBN often has no scan, or has a foreign-language or audiobook jacket. Resolving a title to both is what tools/resolve_isbn.py does. `?default=false` makes the API return 404 rather than a blank pixel when it has nothing, which fires the `onerror` below and reveals the fallback.
